# GeoField Pro

**Профессиональное мобильное приложение полевой геодезии и картографии.**
Прямой конкурент CHCNAV LandStar 8: съёмка, разбивка (вынос), COGO-расчёты и
экспорт — на любом Android-телефоне, без привязки к оборудованию одного вендора.

Собран на Expo React Native (SDK 54). Работает офлайн, интерфейс рассчитан на
работу в поле: тёмная тема под солнце, крупные кнопки под перчатки, тактильный
отклик.

> ⚠️ **Статус:** этот репозиторий содержит сборку **Фазы 2**. Дорожная карта и
> план следующих фаз — в конце файла.

## Возможности (Фаза 2)

- **Навигация как в LandStar** — 4 вкладки: *Проект · Работа · Задачи · Настройки*,
  концепция «активного проекта».
- **Проекты** — создание, список, удаление; всё хранится офлайн в SQLite.
- **GPS/GNSS** — живой поток координат телефона (широта/долгота/высота/точность)
  с индикацией качества RTK **FIX / FLOAT / SINGLE** (эвристика по точности).
- **Съёмка точек** — с **усреднением эпох** (настраиваемое число, порог точности
  с предупреждением), автонумерация `PT001…`, имя/код/примечание.
- **Библиотека кодов объектов** — 7 предустановленных + свои, цвета, выбор кода
  при съёмке.
- **Съёмка линий и полигонов** по вершинам с пунктирным черновиком на холсте;
  автогеометрия: длина, площадь, периметр.
- **БД точек** — поиск по имени/коду, редактирование, удаление.
- **Вынос точки (стейкаут)** — стрелка с учётом компаса, крупная дистанция,
  дельты С/В/H, вибросигнал при попадании в допуск 0.5 м.
- **COGO-калькуляторы** — ПГЗ, ОГЗ, площадь по каталогу (м²/га/сотки), углы ГМС,
  осреднение с СКО. Геодезическая математика покрыта **39 юнит-тестами**
  (`npm test`).
- **Полевой SVG-холст** вместо карты — точки в локальных метрах, автомасштабная
  сетка, север сверху (полноценная карта — в дорожной карте).
- **Экспорт** — CSV точек и GeoJSON всего проекта через системное «Поделиться».

## Запуск

Требуется **Node.js 20 LTS** (Expo SDK 54 не работает на Node 24).

```bash
nvm use 20        # nvm-windows
npm install
npx expo start
```

Отсканируйте QR-код приложением **Expo Go** (Android) — версия Expo Go в сторах
всегда соответствует последнему SDK, поэтому проект должен быть на актуальном SDK.

Если телефон и компьютер в разных сетях:

```bash
npx expo start --tunnel
```

Юнит-тесты геодезической математики:

```bash
npm test
```

## Дорожная карта

| Фаза | Содержание |
|------|------------|
| **3** | Системы координат (UTM / Гаусса-Крюгера, Гельмерт WGS84 ↔ СК-42); парсер NMEA 0183 + демо-RTK; расширение COGO (засечки, проекция точки, деление, углы); автономный APK (`expo prebuild` → `android/`). |
| **4** | Bluetooth SPP → живой NMEA с реального приёмника; NTRIP-клиент для RTK-поправок; MapLibre + офлайн MBTiles; калибровка участка (Гельмерт по парам точек); фото к точкам. |
| **5** | Поверхности TIN, объёмы Cut/Fill, трассы, вынос линий/откосов, импорт DXF, голосовые события. |
| **6** | Бэкенд: аккаунты, совместная работа бригад, синхронизация, МНК-уравнивание. |
| **7+** | iOS, AI-функции (классификация по фото, детекция ошибок, AR), LiDAR. |

## Известные ограничения

- Точность позиции = GPS телефона (3–15 м); RTK-интерфейс работает в демо-режиме.
- Карта — SVG-холст в локальных метрах; полноценные тайлы (MapLibre) в Фазе 4.
- Реальный Bluetooth GNSS ещё не подключён — Фаза 4.
- Компас в стейкауте зависит от магнитометра телефона (чувствителен к металлу).
