# GeoField Pro

**Профессиональное мобильное приложение полевой геодезии и картографии.**
Прямой конкурент CHCNAV LandStar 8: съёмка, разбивка (вынос), COGO-расчёты и
экспорт — на любом Android-телефоне, без привязки к оборудованию одного вендора.

Собран на Expo React Native (SDK 54). Работает офлайн, интерфейс рассчитан на
работу в поле: тёмная тема под солнце, крупные кнопки под перчатки, тактильный
отклик.

> ⚠️ **Статус:** этот репозиторий содержит сборку **Фазы 3**. Дорожная карта и
> план следующих фаз — в конце файла.

## Возможности

### Фаза 2 — съёмка

- **Навигация как в LandStar** — 4 вкладки: *Проект · Работа · Задачи · Настройки*,
  концепция «активного проекта».
- **Проекты** — создание, список, удаление; всё хранится офлайн в SQLite.
- **GPS/GNSS** — живой поток координат с индикацией качества RTK
  **FIX / FLOAT / SINGLE**.
- **Съёмка точек** — с **усреднением эпох** (настраиваемое число, порог точности
  с предупреждением), автонумерация `PT001…`, имя/код/примечание.
- **Библиотека кодов объектов** — 7 предустановленных + свои, цвета.
- **Съёмка линий и полигонов** по вершинам; автогеометрия: длина, площадь, периметр.
- **БД точек** — поиск по имени/коду, редактирование, удаление.
- **Вынос точки (стейкаут)** — стрелка по компасу, дельты С/В/H, вибросигнал
  в допуске 0.5 м.
- **Полевой SVG-холст** вместо карты — точки в локальных метрах, север сверху.

### Фаза 3 — системы координат, GNSS-конвейер, COGO

- **Системы координат проекта** — WGS84, **UTM** (WGS84) и **Гаусса-Крюгера**
  (Красовский / СК-42) с выбором зоны при создании проекта.
- **Картографическая математика** — поперечная Меркатора через серии Крюгера
  3-го порядка (round-trip суб-мм), 7-параметрический **Гельмерт** WGS84 ↔ СК-42.
- **Живые плоские N/E** на экране съёмки и колонки **Northing/Easting** в CSV.
- **GNSS-конвейер** — парсер **NMEA 0183** (GGA/RMC/GST, контроль суммы) и
  **демо-RTK-приёмник** (сценарий Single → Float → Fixed) через один парсер;
  экран **«Подключение GNSS»** с выбором источника.
- **COGO-калькуляторы** — ПГЗ, ОГЗ, площадь, углы ГМС, осреднение с СКО;
  **линейная и прямая засечки**, проекция точки на линию, деление отрезка
  с ведомостью, угол поворота.
- **Экспорт и бэкап** — CSV (с N/E) и GeoJSON проекта, **резервная копия всей БД**
  в JSON через системное «Поделиться».

Геодезическая математика и парсер NMEA покрыты **99 юнит-тестами** (`npm test`).

## Запуск

Требуется **Node.js 20 LTS** (Expo SDK 54 не работает на Node 24).

```bash
nvm use 20        # nvm-windows
npm install
npx expo start
```

Отсканируйте QR-код приложением **Expo Go** (Android) — версия Expo Go в сторах
всегда соответствует последнему SDK, поэтому проект должен быть на актуальном SDK.

Если телефон и компьютер в разных сетях:

```bash
npx expo start --tunnel
```

Юнит-тесты геодезической математики:

```bash
npm test
```

## Известные ограничения

- Точность позиции = GPS телефона (3–15 м); RTK-интерфейс работает в демо-режиме
  (реальный приёмник по Bluetooth — Фаза 4).
- СК-42 — обобщённый датум ~1–2 м; точные региональные МСК — через калибровку
  участка (Фаза 4).
- Карта — SVG-холст в локальных метрах; полноценные тайлы (MapLibre) — Фаза 4.
- Компас в стейкауте зависит от магнитометра телефона (чувствителен к металлу).
